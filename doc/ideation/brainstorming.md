# Ideation & Brainstorming - SKINNOVA
## Problem Statemen
People face skin problems but don't know:
- Which product to use
- Whether they need a doctor
- If the problem is serious

## Our Solution Idea: SKINNOVA

### Feature 1: AI Skin Analysis
- User clicks photo of skin
- AI model detects problem (Acne, Eczema, Pigmentation, etc)
- Gives confidence score: e.g., "85% Acne"

### Feature 2: Smart Product Recommendation
- Based on skin type and problem, suggest affordable products
- Show ingredients to avoid
- Daily routine suggestion

### Feature 3: Doctor Connect
- If AI confidence < 70% or serious issue, auto-connect to dermatologist
- Video consultation option

### Feature 4: Skin Health Tracker
- Daily progress tracking
- Before/After comparison
- Reminders for skincare

## Target Users
1. Teenagers (Acne problem)
2. Women (Pigmentation, skin care)
3. People in remote areas (No dermatologist nearby)

## Tech Stack (Idea)
- Frontend: Flutter App
- Backend: Python + TensorFlow (AI Model)
- Dataset: HAM10000 + Indian Skin Dataset
- Database: Firebase

## Why This Will Win SIH?
- Social Impact: Helps millions with skin issues
- Innovation: AI + Healthcare combo
- Feasible: Can be built in 3 months
- Business Model: Freemium
